# 立创实战派 ESP32-S3 相机固件

把立创实战派 ESP32-S3 开发板变成一台简单的小相机：屏幕取景、按键拍照、照片存 TF 卡、手机网页看相册。摄像头只有 30 万像素（640×480），成像偏柔、带点噪，正好仿老 CCD 卡片机的味道。

与同板子的 [Muse 语音固件](https://github.com/haoinvest-cpu/muse-esp32-s3-lichuang) 是两个独立固件，可互刷切换。

## 功能（v4.2）

- **LCD 实时取景，画面自动旋转**：板载 QMI8658A 六轴传感器判重力方向，横/竖四种握持画面都自动转正（带迟滞，45° 附近不乱跳）；状态行（照片数等）跟着画面一起转
- **按键拍照**：短按 BOOT 键快门，JPEG 编码存 TF 卡 `/DCIM/IMG_xxxx.JPG`；拍照有快门声（ES8311 播放与 Muse 固件同款的“吱”声 chirp）
- **网页相册**（同一局域网）：单页设计，点照片就地看大图、点下载原地存文件（不跳页）、可删除、可网页遥控快门
- **AP 配网**：无 WiFi 凭据时自动开热点 `LennonCam-Setup`（192.168.4.1），网页扫描选网、输密码保存到 NVS；换网络时长按 BOOT 5 秒清除凭据重新配网
- 拍照**不镜像**（HMIRROR=0）、照片**不加任何水印**

## 硬件

| 部件 | 型号/规格 |
|---|---|
| 开发板 | 立创实战派 ESP32-S3（N16R8：16MB Flash / 8MB PSRAM） |
| 摄像头 | GC0308，最大 640×480，RGB565 输出 + 软件 JPEG 编码（无硬件 JPEG） |
| 屏幕 | ST7789 320×240 |
| 姿态传感器 | QMI8658A（加速度+陀螺，I2C） |
| 音频 | ES8311 + 板载喇叭（功放使能经 PCA9557 bit1） |
| 存储 | TF 卡，FAT32，≤32GB |

注：摄像头电源经 I2C 扩展芯片 PCA9557（代码注释里也写作 TCA9557）bit2 拉低使能；板上只有 BOOT 键（GPIO0）一个可用按键，短按=快门、长按 5 秒=清 WiFi 凭据。

## 构建与烧录

环境：ESP-IDF **6.0.1**。

```bash
. ~/esp/esp-idf-v6.0.1/export.sh
idf.py build
idf.py -p /dev/ttyUSB0 flash    # 或只刷应用分区，见下
```

分区未改动（bootloader 0x0 / 分区表 0x8000 / 应用 0x10000，应用分区 4MB），已有本固件时可只刷应用：

```bash
python -m esptool --chip esp32s3 -p /dev/ttyUSB0 -b 460800 write_flash 0x10000 build/camera_app.bin
```

首次开机无凭据会自动进配网模式，屏幕顶部会显示 `SETUP: LennonCam-Setup`。

## 踩坑记录（省得你再踩）

1. **QMI8658A 连续多字节 I2C 读不会自动递增寄存器地址**：一口气读 0x35 起 6 字节，拿到的全是同一个字节重复六遍，三个轴数值永远相同——方向判断从源头就是错的。必须**逐字节单读**（0x35–0x3A 分开读），本工程 `imu_orient.c` 就是这么读的。方向标定数据（±8g，4096/1g）：横 ax≈+3550 → 不转；竖 ay≈+4150 → 90°；反横 ax≈-3750 → 180°；反竖 ay≈-3290 → 270°。az 是板面法向分量，只用来判“近乎平放”，不参与选方向。
2. **GC0308 必须按 VGA 初始化**：先按 QVGA 初始化再切 VGA，驱动不会重分配帧缓冲（缓冲按 QVGA 一半大小申请），成片必然花屏。开机就 VGA。
3. **官方例程的 HMIRROR=1 是自拍预览设置**：拿它拍照，成片是镜像的。拍照用途要 HMIRROR=0，也不要加 vflip，这块屏和传感器装的方向本来就是正的。
